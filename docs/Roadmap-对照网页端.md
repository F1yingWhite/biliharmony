# BiliHaromny Roadmap —— 对照 B 站网页端的功能差距

> 2026-08-15 盘点，以 `entry/src/main/ets` 实际代码为准，对照 www.bilibili.com 网页端功能。
> 已实现功能见根目录 `README.md`，本文只列**未做**项。

---

## 1. 内容分区类

| 功能 | 说明 | 现状线索 |
| --- | --- | --- |
| 番剧/影视专区索引 | 新番时间表、番剧索引 | 已有 `BangumiDetail` 详情页（选集/评分/追番），索引聚合未做 |
| 专栏（文章） | 文章阅读页、文集 | 专栏搜索已可跳系统浏览器打开 `bilibili.com/read/cv{id}`，阅读页未做 |
| 分区频道页 | 各分区落地页（游戏/知识/动画…） | 无 |
| 排行榜 | 全站排行、每周必看、入站必刷 | ✅ 已实现（`pages/RankPage.ets`，首页热门频道入口） |

## 2. 搜索

已有：综合/视频/番剧/影视/直播/专栏/用户七 Tab，视频排序 chips + 筛选面板，番剧/影视跳 `BangumiDetail`，直播跳 `LiveRoom`，直播排序（人气/最新开播）。

未做：

- 用户类型筛选（全部/UP主/普通/认证）
- 搜索热词推荐等更多搜索增强（默认词、搜索发现）可按需补

## 3. 动态

已有：点赞/转发、分类筛选（全部/视频/番剧/专栏，`type=all/video/pgc/article`）、表情图文混排、转发展示。

未做：

- 发布动态（文字/图片/转发）
- 顶部关注 UP 主横滑栏（直播中带 Live 角标）

## 4. 消息中心

已有：私信会话列表 + 聊天、回复我的 / @我 / 收到的赞 / 系统通知四个通知 Tab、未读角标。

未做：

- 通知页内更多筛选/批量已读等增强操作

## 5. 播放器 / 观看体验

已有：CC 字幕、UGC 合集选集 + 播完自动下一集、弹幕 protobuf 分段加载、弹幕列表面板、屏蔽词/正则/屏蔽用户管理、评论排序切换（最新/最热）。

未做：

- 自动连播/播完暂停设置（当前仅 UGC 合集自动连播）
- 画中画 / 后台播放
- 历史弹幕（按日期）
- 弹幕举报
- 高级弹幕
- 视频笔记、互动视频（剧情树）

## 6. 收藏与稍后再看

已有：稍后再看、收藏夹/收藏集浏览、收藏夹管理（新建/重命名/删除/批量移动）。

未做：

- 追番 / 追剧列表
- 收藏夹排序（服务端自定义排序）

## 7. 直播

已有：观看、WebSocket 弹幕收发、醒目留言、画质切换。

未做：

- 送礼 / 礼物面板 / 上舰（消费类，可长期不做）
- 直播分区页
- 主播开播提醒
- 直播回放

## 8. 账号与其他

- 大会员 / 充电 / 钱包相关
- 离线缓存（下载）
- 举报（视频/评论/弹幕）
- 黑名单管理
- 登录设备管理
- 首页负反馈（不感兴趣 / 屏蔽 UP 主）
- 网页端的创作中心、会员购、漫画、课堂：第三方客户端通常不做，不列入计划

---

## 建议实施顺序

| 优先级 | 事项 | 理由 |
| --- | --- | --- |
| P5 | 专栏文章阅读页 | 专栏搜索已有落地，阅读体验仍缺失 |
| P5 | 分区频道页 + 番剧/影视索引 | 浏览链路从首页只进推荐/热门，分区入口缺失 |
| P6 | 发布动态 | 动态从只读变互动后，还缺发布闭环 |
| P6 | 顶部关注 UP 主横滑栏 | 动态流导航效率提升 |
| P7 | 自动连播设置 + 画中画/后台播放 | 观看体验继续向网页端对齐 |
| P8 | 历史弹幕 / 高级弹幕 | 弹幕体系增强 |
