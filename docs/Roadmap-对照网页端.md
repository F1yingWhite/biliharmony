# BiliHaromny Roadmap —— 对照 B 站网页端的功能差距

> 2026-08-15 盘点，以 `entry/src/main/ets` 实际代码为准，对照 www.bilibili.com 网页端功能。
> 已实现功能见根目录 `README.md`，本文只列**未做**项。

## 2. 搜索

已有：综合/视频/番剧/影视/直播/专栏/用户七 Tab，视频排序 chips + 筛选面板，番剧/影视跳 `BangumiDetail`，直播跳 `LiveRoom`，直播排序（人气/最新开播），**用户类型筛选（全部/UP主/普通/认证）+ 粉丝数/等级排序**。

未做：

- 搜索热词推荐等更多搜索增强（默认词、搜索发现）可按需补

## 3. 动态

已有：点赞/转发、分类筛选（全部/视频/番剧/专栏）、表情图文混排、转发展示、顶部关注 UP 主横滑栏、**发布纯文字动态**（右下角 FAB + 输入面板，`BiliApi.publishDynamic`）。

未做：

- ✅ 已实现：发布图文动态（`upload_bfs` multipart 上传 + `create/dyn` scene=2 JSON body，图片九宫格选图）与转发动态

## 4. 消息中心

已有：私信会话列表 + 聊天、回复我的 / @我 / 收到的赞 / 系统通知四个通知 Tab、未读角标。

未做：

- 通知页内更多筛选/批量已读（网页端亦无批量已读接口）

## 5. 播放器 / 观看体验

已有：CC 字幕、UGC 合集选集 + 播完自动下一集（无合集时自动连播相关推荐第一条）、弹幕 protobuf 分段加载、弹幕列表面板、**弹幕举报**（播放画面点击弹幕即弹原因菜单）、屏蔽词/正则/屏蔽用户管理、评论排序切换（最新/最热）。

未做：

- 画中画 / 后台播放
- 历史弹幕（按日期）
- 高级弹幕
- 视频笔记、互动视频（剧情树）

## 6. 收藏与稍后再看

已有：稍后再看、收藏夹/收藏集浏览、收藏夹管理（新建/重命名/删除/批量移动）。

未做：

- 收藏夹排序（服务端自定义排序）

✅ 已实现：追番 / 追剧列表（`pages/BangumiListPage.ets`，我的页面入口，番剧/影视标签切换 + 分页加载）

## 7. 直播

已有：观看、WebSocket 弹幕收发、醒目留言、画质切换、✅ 直播分区页（`pages/LiveZonePage.ets`）。

未做：

- 送礼 / 礼物面板 / 上舰（消费类，可长期不做）
- ~~直播回放~~（2026-09-21 决议：主播开启录播后的直播间内往期片段，UP 主通常自行剪辑投稿为普通视频，客户端无需单独适配）

✅ 已实现：主播开播提醒（轻量版）——动态页关注 UP 横滑栏按 UP 批量查询开播状态，直播中的头像标「直播中」红点（`room/v1/Room/get_status_info_by_uids`，`DynamicView.refreshLiveBadges`）

## 8. 账号与其他

- 大会员 / 充电 / 钱包相关
- 离线缓存（下载）
- 举报（视频/评论/弹幕）——✅ 评论举报（更多菜单 + WBI）、弹幕举报（点击播放内弹幕）已实现；视频举报无公开接口未实现
- ✅ 黑名单管理
- 登录设备管理（无公开接口，范围外已明确）
- ✅ 首页负反馈（长按信息流卡片「不感兴趣」本地隐藏，Web 无服务端反馈接口）
- 网页端的创作中心、会员购、漫画、课堂：第三方客户端通常不做，不列入计划

✅ 已实现：定时深色切换（「我的」页开关 + 开始/结束时间选择，跨天时段自动生效）
✅ 已实现：发布纯文字动态（`DynamicView` 右下角 FAB + 输入面板，`publishDynamic`）
✅ 已实现：自动连播/播完暂停（播放器开关；UGC 合集播下一集、无合集自动播相关推荐第一条）
