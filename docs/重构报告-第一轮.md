## 本轮落地（净 -184 行，新增 3 个共享模块 + 1 个组件）

### P0 正确性修复（3 项）
1. **toast 递归崩溃**：`VideoDetail/UserSpace/DynamicDetail/Login` 4 处 `private toast()` 方法体写成了 `this.toast(message)` 自我递归，被 catch 吞掉 → **所有 toast 静默失效**（43+15 处调用点，含关注/点赞/投币/收藏/举报反馈）。新建 `common/Toast.ets: safeToast()`，4 处改为安全实现。
2. **ActionResult 双类分裂**：`BiliApi.ets` 内复制了 `ApiCommon` 的 `ActionResult/getData/actionWithCsrf/postVideoAction` 共 88 行 → UI 层从 `BiliApi`、域模块从 `ApiCommon` 拿到的是**两个不同类型**，靠结构同型才没报错。删除副本，统一从 `internal/ApiCommon` import 并 `export { ActionResult }` 保持调用方不变。
3. **LivePlayerView 换源死锁**：`restartForSource` 递增 `playerGeneration` 期间在途 `initPlayer` 的 `finally` 只在 `generation === playerGeneration` 时复位 `playerCreating` → 换源/切线路后 `playerCreating` 永久 true，所有 `initPlayer` 被入口守卫挡掉，**直播黑屏不可恢复**。改为无条件复位 + 换源前等待在途创建退场。
